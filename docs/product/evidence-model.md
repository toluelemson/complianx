# Evidence model

Evidence belongs to a project and section, has a generated storage name, checksum, version, provenance metadata, uploader, and review state. Replacements create a new version linked to the previous artifact.

Requirements link to evidence through obligation evidence records. The traceability view connects the regulatory pack version, requirement, action, evidence, evaluation, review, approval, and package inclusion.

Finalized package archives are immutable snapshots. Evidence referenced by a finalized package is retained so its provenance remains inspectable.
